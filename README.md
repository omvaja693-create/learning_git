# 🎬 Netflix Data Analysis Dashboard (Power BI)

## 📌 Project Overview
This project is a **Power BI dashboard** built to analyze **Netflix movies and TV shows**.  
It provides insights into content distribution, genres, ratings, countries, and release trends using interactive visualizations.

The dashboard helps users **explore Netflix data visually** and understand patterns in streaming content.

---

## 🛠️ Tools & Technologies Used
- 🧠 **Power BI Desktop**
- 📊 **Data Visualization**
- 🗂️ **Data Modeling**
- 📁 **PBIX File Format**
- 🧹 **Basic Data Cleaning**

---

## 📂 Project Files
- 📊 `netflix_dashboard.pbix` → Power BI dashboard file

## 📈 Dashboard Features
✔️ Total Movies & TV Shows count  
✔️ Content distribution by **Type (Movie / TV Show)**  
✔️ Analysis by **Genre**  
✔️ Content by **Country**  
✔️ Ratings breakdown  
✔️ Year-wise release trends
